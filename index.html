How to Use

  1. Create a new Discord Application at Discord Developer Portal
  2. Enable MESSAGE CONTENT INTENT and SERVER MEMBERS INTENT
  3. Invite the bot with Administrator permission
  4. Encode the bot token: open console (F12) on any page and type btoa('YOUR_TOKEN')
  5. Update console-builder.js with your Vercel URL, encoded token, guild ID, and log channel ID
  6. Open any website, press F12, paste console-builder.js content, press Enter
  7. All IDs print in console + .env copies to clipboard
